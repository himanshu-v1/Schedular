# Schedular
NativeScript based mobile app to schedule daily tasks and set temporary reminders.

# Features
- Add reminders for monthly/weekly/daily recurring events and get ___notification alert___ on specified time.
- Add a task list or a non-recurring event to be notified about at specific time which get's discarded once done.
- Data is maintained ___device's permanent storage___ and stays even if you kill the app.
- ___Fingerprint___ authentication on app launch for added privacy.
- Inbuilt interactive calendar to choose dates to create events with ease, like Google Calendar.
- Notification drawer applies same theme as app (was a challange back in 2019).

_Note:_ App supports Android devices only as part of initial roadmap.
